# 💗 Proyecto "safe space" 🕯️✨💗

¡Hola! Este proyecto es una pequeña web devocional, donde podés ver oraciones interactivas de distintos santitos, con estilo limpio y toques emocionales 💗

✅ Secciones full screen (100vh)  
✅ Galería interactiva al final
